# 下载设计：资料如何变成文件

本文只解释数据结构和处理流程，不列出 manifest、depot key 或 Lua 的获取渠道。仓库没有附带游戏资料和运行中的资料服务。

## 各项资料的作用

| 内容 | 作用 |
| --- | --- |
| AppID / 游戏信息 | 确定游戏、安装目录、分支和适用的 depot |
| Depot ID | 标识一组可安装内容 |
| Manifest GID | 指定该 depot 的一个具体版本 |
| Manifest | 描述文件名、大小、标志、分块摘要和写入偏移 |
| Depot key | 解密相应 depot 的加密文件名或内容块 |
| Lua | 可选的文本声明格式；解析声明，不运行脚本 |

这些内容必须对应同一版本。只有清单而没有所需密钥，不能完成相应内容的解密。密钥本身也不包含文件列表。

## 处理顺序

1. 从使用者提供的本地资料或配置接口读取游戏信息。
2. 根据本体、勾选 DLC 和目标语言，选择适用的 Windows public depot。
3. 读取对应版本的 manifest，解析文件及分块位置。
4. 从 Steam 内容分发节点读取内容块。
5. 使用对应 depot key 解密，再解压 VZ / VZstd 等载荷。
6. 将块写入目标文件的指定偏移，并追加完成记录。
7. 本体任务完成后登记安装元数据；仅补装 DLC 时保留已有本体安装记录。

内容块的完整性判断与清单对应；暂停或退出时保留已完成块的记录。续传使用保存的计划和清单，不从头开始整款游戏。

## 文件名、IV 与加密内容

Steam 内容格式中的 IV 与数据一起编码，不能统一替换成全零。实现按格式取出加密 IV，使用相应密钥恢复 IV，再处理后续内容。Lua 只是元数据的文本载体，与文件块加密是两层不同的处理。

## 安装位置与恢复

游戏文件进入选择的游戏库下的 `steamapps/common`。任务计划、块记录和缓存位于 Bear 的 `data`。完成后写入 Steam 安装元数据；这一步只描述磁盘上的安装状态，不授予账号许可。

删除未完成任务时先停止对应工作进程，再按用户选择移除任务记录或未完成文件。已登记安装的内容按保留规则处理。

## DLC 与本体目录

游戏库保留每个 DLC 的独立记录、映射及启用状态，在界面上按 `ParentId` 折叠到本体下。搜索 DLC 名称或 AppID 会显示所属本体及匹配子项。没有本体记录时显示归属卡片，不自动启用本体映射；未知归属的条目仍可查看。本体资料中的 DLC 列表可直接补齐旧条目的归属，不要求每个子 DLC 的商店详情都可用。

下载窗口的“同时下载游戏本体”控制下载范围：

| 选择 | 下载范围与目标位置 |
| --- | --- |
| 勾选，同时选择 DLC | 本体加选中的 DLC，安装到所选游戏库的本体目录 |
| 取消勾选，并选择 DLC | 仅补装选中的 DLC，自动定位已安装本体，或使用手动选择的本体目录 |

DLC 的文件按 manifest 中的相对路径写入本体目录，不以 DLC 名称另建独立游戏目录。手动选择的是实际本体文件夹，不是 `steamapps/common` 总目录。仅补装时保留现有本体安装记录。

独立下载需要该 DLC 确实包含内容文件，且对应版本的 manifest、depot key 等必要资料齐全。某些 DLC 没有独立内容 depot，文件可能已经在本体中；商店存在 DLC 条目并不意味着它有单独文件包。DLC 选择决定独立 DLC 内容的下载范围，随本体提供的文件仍以本体清单为准。当前仅处理适用的 Windows public 内容，不提供任意分支切换。

DLC 补装任务与本体共用目录。移除这类任务只清理任务记录与缓存，不删除本体目录或本体文件，也不表示卸载该 DLC。

## 网络层

代理配置优先。未使用代理时可尝试本地 SNI 模式：连接目标节点、在 TLS 握手中省略域名 SNI，但 HTTP Host 和证书名称认证仍使用原始域名。无法通过认证的连接不会继续传输内容。

公开源码不包含运营环境的上游适配器、账号令牌、默认资料服务地址或资料收集脚本。

## 客户端访问策略与下载暂停

1.8.19 的可选访问策略与游戏内容下载分开处理。公开构建默认不启用，需要自行配置服务。在线客户端约每 60 秒检查策略；服务拒绝访问时先停止任务、保存下载进度，再显示可恢复的访问状态。恢复许可后可以重新进入并继续任务。

本地记录绑定硬件摘要。已有许可可在服务给出的离线期限内继续使用，默认约 24 小时；离线期限届满后需要联网。已经缓存的拒绝状态会保留，联网得到新许可后清除。策略无法立即作用于离线设备，也不能防止使用修改后的客户端。

程序更新仅获取版本元数据。检测到新版后询问是否打开蓝奏云网页，不在下载任务中接收或替换程序。配置与接口约定见 [配置说明](configuration.md)。
