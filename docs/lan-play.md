# 局域网联机（试用）

Bear 通过独立的 Goldberg 核心，为加载 Steam API 的游戏准备局域网配置并启动游戏。配置、核心及模拟器记录保存在程序旁的 `data/lan` 中。

## 开始使用

1. 选择游戏，点击右侧“局域网联机 · 试用”。
2. 选择已安装游戏的 EXE。Bear 尝试查找 `steam_api64.dll` 或 `steam_api.dll`；有多个副本时手动选择游戏实际使用的文件。
3. 点击“下载官方核心”，或导入已解压的 Goldberg `release` 文件夹。当前固定使用经过本地验证的 `release-2026_09_27`，不会自动更新核心。官方包约 13 MiB，只解出本功能需要的组件。下载默认直连，需要时勾选跟随软件代理。
4. 设置昵称与发现端口。每台电脑使用不同的本地玩家 ID。同一局域网通常可自动发现；虚拟局域网或发现失败时，可按行填写好友 IP、域名或 `IP:端口`。
5. 点击“联机启动”，进入游戏内的合作或大厅菜单。需要好友浮层时可尝试实验性的 Shift+Tab 选项。
6. “发现 / 加入大厅”打开核心附带的交互式 `lobby_connect` 工具，按其提示选择游戏启动程序。

各方需要兼容的游戏、模组和核心版本。填写地址本身不会建立虚拟局域网或打通不可达的网络。首版没有 Bear 自己的公网大厅或中继。

## 星露谷物语

AppID 为 **413150**。游戏本身支持原生局域网合作，可以使用“普通启动”，再在游戏内选择合作主持或通过局域网 / IP 加入。

本次开发环境未安装星露谷物语。已经用真实核心、两个本地独立进程和此 AppID 完成了发现、创建及加入大厅测试；这不能替代游戏实机或两台电脑的联机验证。

## 原文件与记录

启用时只为实际覆盖的文件保存一份原始副本。再次应用配置不会累计历史备份。“恢复原游戏文件”恢复原始 DLL 和已有配置，并删除本功能创建的配置文件；不相关文件保留。

“普通启动”先恢复原始 Steam API，再启动所选游戏。更换游戏路径前先恢复原文件。修改文件时应退出游戏。玩家配置与模拟器记录保留；游戏本身的存档位置由游戏管理。

首版接入标准 Steam API 部署和可选实验性浮层。依赖专用官方后端或其他启动机制的游戏，需要另外适配。

## 核心与许可

- 核心由使用者从 [Goldberg 官方发布仓库](https://github.com/Detanup01/gbe_fork/releases/tag/release-2026_09_27) 获取；对应源码见 [同版本标签](https://github.com/Detanup01/gbe_fork/tree/release-2026_09_27)。核心遵循 LGPLv3，可替换。
- 本机已有 7-Zip 时使用现有解包工具；否则按需获取官方公共领域 7zr 组件。没有安装系统服务或驱动。
- SmartGoldbergEmu 是配置与启动体验的参考，本次没有复制其启动器代码。

## 开发验证

先构建程序，再用已经准备好的核心执行以下命令。验证只操作指定输出目录，不读取真实 Steam 账号。

```powershell
.\dist\BearLibrary.exe --lan-test .\obj\lan-tests "核心的 release 文件夹路径"
```

测试覆盖界面部署、原文件恢复、配置持久化、实验性组件部署、启动参数 / AppID / 工作目录传递，以及两个真实 Goldberg 进程在回环网络中发现并加入大厅。
